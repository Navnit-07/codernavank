# codernavankOS

> **Navnit Kumar** — Software Engineer. I turn unreasonable ideas into working systems.

This isn't a portfolio website. It's a fake operating system where **the chessboard is the navigation.**

Move a piece → a part of my work opens. Checkmate the bot → `hire_me.sh` unlocks.

---

## How it works

Every chess piece routes somewhere different:

| Move | Opens |
|------|-------|
| ♟ Pawn | Skills |
| ♞ Knight | Projects |
| ♝ Bishop | Achievements |
| ♜ Rook | Experience |
| ♛ Queen | Hire Me |
| ♚ King (castle) | About |

You can click the board or type real moves in the terminal — `e4`, `Nf3`, `O-O`, all valid.

The terminal also speaks shell: `whoami`, `ls`, `cat experience.log`, `help`.

Your opponent is **Industry Standard** — beatable, occasionally smug, not Stockfish.

---

## Try it

```bash
npm install && npm run dev
```

Then open the local URL and make your first move.
